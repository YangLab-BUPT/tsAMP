# Benchmark Models

This directory contains the running files for benchmark models, including the data and parameters we used. The specific models need to be downloaded from their corresponding GitHub repositories. We provide the files and parameters used during our training, which can be directly placed in the corresponding model directories for use.

## Models

### deep-AMPpred

- **Repository:** https://github.com/1fuyuhe/deep-AMPpred/tree/main

### AMPfinder

- **Repository:** https://github.com/BiOmicsLab/AMPfinder

### iAMPCN

- **Repository:** https://github.com/joy50706/iAMPCN/tree/master

### DiffAMP

- **Repository:** https://github.com/wrab12/diff-amp

### AMPlify

**Usage:**

```bash
AMPlify -s "/tsAMP/data/tsAMP-I/test_amp.fasta"
```

## How to Use

1. Download the model source code from the corresponding GitHub repository.
2. Place the provided training files and parameters into the corresponding model directory.
3. Run the model according to its documentation.
